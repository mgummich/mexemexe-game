# 07 — 10–20 Minute Match Pacing

Goal: make the same core rules feel like an escalating match rather than a flat repeated turn loop.

- **PACE-01** Shape presentation into opening → developing table → high-chaos Mexe → endgame pressure without changing rules.
- **PACE-02** Keep early simple actions fast and visually quiet.
- **PACE-03** Increase presentation energy as table reuse/rearrangement becomes meaningful.
- **PACE-04** Create a hidden match-intensity/table-heat value derived from game state, not elapsed time.
- **PACE-05** Candidate inputs: table card count, meld count, recent committed rearrangements, lowest hand size, deck state.
- **PACE-06** Use calm/active/hot presentation tiers to drive audio/reaction strength without changing legality.
- **PACE-07** Internally classify draw, simple play, new meld, Mexe, big Mexe, threat turn and finishing attempt.
- **PACE-08** Compress boring turns; allow interesting moves enough time to read.
- **PACE-09** Make presentation duration proportional to information content rather than fixed per turn.
- **PACE-10** Add rare match moments such as `MESA VIROU`, `MEXEU BONITO`, `ÚLTIMA CARTA`; keep them uncommon.
- **PACE-11** Apply cooldowns and no-immediate-repeat rules to character lines/reactions.
- **PACE-12** Use subtle recent-move highlighting to give the shared table a sense of transformation/history.
- **PACE-13** Promote hand-size race visually as players approach 3/2/1 cards.
- **PACE-14** Recognize meaningful comeback states for optional presentation, without creating a scoring system.
- **PACE-15** Make draw-pile depletion visible; thin the deck and expose low-deck pressure.
- **PACE-16** Treat hand-empty race and deck-exhaustion race as separate natural endgame pressures.
- **PACE-17** Add enough music/SFX variation to avoid 20-minute repetition fatigue.
- **PACE-18** Do not add random events/power-ups to Classic to solve pacing. Any future Party mode stays separate.

Verification: simulated/recorded long matches, draw-heavy stretches, large-table midgame, close endgame; measure where actual users report slowdown.
