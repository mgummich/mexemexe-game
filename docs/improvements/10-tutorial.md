# 10 — Tutorial / Onboarding

Goal: get a new player to the first satisfying Mexe quickly, with action-driven teaching and minimal reading.

- **TUTORIAL-01** Start with immediate player control; avoid welcome paragraphs.
- **TUTORIAL-02** Teach a run through action.
- **TUTORIAL-03** Teach a set/trinca through action.
- **TUTORIAL-04** Teach draw contextually and state that drawing ends the turn.
- **TUTORIAL-05** Introduce Mexe within roughly 60–90 s; target first successful Mexe within ~2–3 min.
- **TUTORIAL-06** Use an explicit table-card reuse puzzle as the core `aha` moment.
- **TUTORIAL-07** Intentionally create a temporary invalid state and explain that this is normal while editing.
- **TUTORIAL-08** Teach the core rule with concise language such as `PODE BAGUNÇAR. SÓ PRECISA ARRUMAR ANTES DO FEITO.`
- **TUTORIAL-09** Teach FEITO by showing it wake up when the table becomes valid, not via long rules copy.
- **TUTORIAL-10** Teach Undo through a harmless mistake to communicate safe experimentation.
- **TUTORIAL-11** Do not spend required onboarding time on Redo/Reset/advanced controls unless necessary.
- **TUTORIAL-12** Finish with a small final Mexe that empties the hand, includes any required final repair, then `BATER!`.
- **TUTORIAL-13** End in a mini victory and transition directly to the first real match; avoid returning to menu unnecessarily.
- **TUTORIAL-14** Let Beginner assistance continue onboarding during that first match.
- **TUTORIAL-15** Group the experience conceptually into `BAIXAR`, `COMPRAR`, `MEXER`, `BATER` even if internal state has more steps.
- **TUTORIAL-16** Keep copy very short and prefer visual card examples over paragraphs.
- **TUTORIAL-17** Consider Dona Cida as mentor if consistent with character direction.
- **TUTORIAL-18** Keep `Pular` available but secondary.
- **TUTORIAL-19** Save progress at meaningful lesson checkpoints if existing persistence supports it cleanly.

Verification: silent first-time playthrough, completion/skip/resume, PT/EN, mobile, reduced motion, first-match transition.
