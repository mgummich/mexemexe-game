# 01 — Main Menu

Goal: make the existing menu clearer for first-time players, stronger in brand identity, and more alive without redesigning it.

- **MENU-01** Always show `ARRUMA. DESARRUMA. BATE.` under the real logo, not only fallback rendering.
- **MENU-02** First run: primary `APRENDER A JOGAR` + `~3 MIN`; secondary `JOGAR DIRETO`. After tutorial completion restore `JOGAR` primary and `TUTORIAL` secondary.
- **MENU-03** Demote Rules, language and Settings into compact utilities while preserving accessible hit targets.
- **MENU-04** Present `JOGAR ONLINE` with a small `ALPHA` badge; preserve offline explanation/disabled behavior.
- **MENU-05** Replace constant logo bobbing with intermittent idle personality motion; respect reduced motion and scene cleanup.
- **MENU-06** Give the main CTA stronger hover/press/impact feedback than secondary buttons without slowing navigation.
- **MENU-07** Add a short entrance sequence: background → logo → tagline → primary CTA → secondary controls; roughly 500–700 ms normal motion.
- **MENU-08** Add sparse environmental motion where existing assets allow it: bulb flicker, flags, small props. Avoid continuous distraction.
- **MENU-09** If suitable assets/infrastructure already exist, add quiet boteco ambience; otherwise defer rather than add placeholder audio.
- **MENU-10** Add a short non-interactive teaser showing cards being rearranged between legal combinations. Keep it occasional and presentation-only.

Verification: first-run, returning, PT/EN, reduced-motion, large-text, narrow/wide, offline states; verify no duplicate navigation or animation leaks.
