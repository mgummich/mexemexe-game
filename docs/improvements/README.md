# MEXEMEXE Experience Improvement Backlog

These files contain the actionable UX, game-feel, pacing, onboarding, mobile, online and replayability backlog derived from the product review.

Use `AGENTS.md` for execution rules. Implementation sessions should normally load only this index plus the relevant backlog file(s).

## Product Direction

MEXEMEXE should feel warm, tactile, playful, clever, social, slightly mischievous and boteco-inspired. It should remain readable and calm between meaningful events.

Core principles:

- show rather than explain;
- boring actions move quickly, important actions breathe;
- errors teach instead of punish;
- temporary invalidity is normal during Mexe;
- animation communicates what changed;
- audio confirms interaction and match intensity;
- characters make AI turns socially readable;
- advanced controls stay quiet until useful;
- late-game state should feel more intense than early game;
- reduced-motion/mobile behavior must preserve meaning.
