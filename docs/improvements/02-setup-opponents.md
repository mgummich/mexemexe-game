# 02 — Setup / Opponent Selection

Goal: make setup feel like choosing who sits at the table, not configuring anonymous AI.

- **SETUP-01** Show each AI with name, avatar and truthful short personality descriptor.
- **SETUP-02** Add short character lines/quotes where they fit the tone.
- **SETUP-03** Replace hidden one-way cycling with visible previous/next controls.
- **SETUP-04** Add compact character-change animation and character-specific feedback/SFX where supported.
- **SETUP-05** Keep personality conceptually separate from AI difficulty; do not imply a character is inherently easy/hard unless true.
- **SETUP-06** Give 2/3/4-player choices lightweight descriptors that explain match character.
- **SETUP-07** Replace redundant match-summary copy with useful information: style, recommendation, or evidence-based duration.
- **SETUP-08** Recommend a beginner-friendly opponent only if actual AI behavior supports the claim.
- **SETUP-09** Prevent accidental duplicate named AI opponents; skip, swap or otherwise preserve uniqueness.
- **SETUP-10** Use spare space for character/table presence rather than more settings; consider seating preview if clean.
- **SETUP-11** Consider a thematic title such as `MONTE A MESA` if localization/style support it.
- **SETUP-12** Make `JOGAR` transition via quick shuffle/deal/table movement rather than only a generic fade.
- **SETUP-13** Preserve lineup through Settings and keep seeds/replay-test controls secondary/Advanced.

Verification: 2/3/4 players, all personalities, no duplicate-selection traps, mobile layouts, settings round-trip, PT/EN.
